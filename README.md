# Practice Pads

A browser-based practice workspace scaffold for scales, modes and sustained chord pads. Feature engines and the workspace are not implemented yet.

## Local development

Assumptions: Node 24 (tested with 24.18.0) and npm 11 (tested with 11.16.0). Run `npm ci`, `npm run dev`, or `npm run check` (typecheck, Vitest and Vite production build). The static build uses `/practice-pads/` as its base; no hosting is enabled.
