# Integration and release checks

The production entry composes the controlled workspace, Tonal theory, Tone audio, VexFlow notation and fretboard.js. It starts at D jazz melodic minor, degree III. Changing derivative mode retains the parent and position. Relative-key changes use Tonal data and remember the selected minor family. Self-guided UI and its controller state have been removed.

CAGED is the full-width study panel; notes/intervals and mode notation share the row above it and stack on phones. Seven note/interval cells share a concise role legend. Technical and note-position descriptions remain available to assistive technology rather than filling the visible page. Position uses the library's cropping option with actual fret numbers. Full neck keeps one stable overview through the highest fret used by any reference position or local mapping for that parent; switching shapes changes only the highlighted notes. Selected notes stay opaque and background circles/labels fade to 30%, retaining tonic color. The browser remembers that view. Modal-tonic dots and the tonic note cell are teal; asterisks and Diagram info are removed.

The five major templates are source-provided. All three minor families now have five reference-derived position maps, not a full-neck fallback. [Sources, transcription and inferred shape identity](minor-caged-sources.md) need independent musician review. These dots do not define finger numbers or an exercise. The touch fretboard editor accepts an ordered sequence for each parent/family/position; diagram and exercise use those same events. Storage and compact backup format are unchanged. See the [practice guide](practice.md) and [visualization reference and notices](visualization.md).
